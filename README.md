# paraagent

Official repository for **ParaAgent: Reinforcing Parallel Acting in Open-World Tool Environments**.

[Paper](https://arxiv.org/abs/2609.33618) · [SFT Dataset](https://huggingface.co/datasets/ShengbinYue/paraagent-sft)

## Overview

ParaAgent learns to explore, plan, and act in parallel in open-world tool environments. Its ParaAct interaction framework supports parallel tool retrieval and dependency-aware parallel tool execution, with agent behavior trained through supervised fine-tuning and reinforcement learning.
